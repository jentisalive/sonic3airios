### What's changed

- **Added English installation instructions** to the empty Mods screen.
- **Added Open mods folder:** opens the native Files picker with the game's actual `Documents/mods` folder as its starting location.
- **Creates the mods folder if missing.** Browsing does not import or replace files.
- **Keeps the restart reminder:** restart the game after adding mods so it scans the new folders.
- **Includes earlier improvements:** Retina output and iPhone/iPad app icons.

### Install & play

1. Download **Sonic3AIR-iOS-unsigned.ipa** from **Assets** below.
2. Sign and install it using your compatible sideloading method.
3. Launch **Sonic 3 AIR** and select your own compatible, unmodified **Sonic 3 & Knuckles ROM** in Files.

> The ROM is not included or downloaded. This IPA is unsigned and requires signing before installation. Keep the app's Documents folder when updating to preserve saves, settings and mods.

### Mods & saves

Find the app's writable files in **Files → On My iPhone / On My iPad → Sonic 3 AIR**. Extract mod folders into **mods**, then restart the game to scan for them.

### Validation

Native arm64 iOS compilation, app bundle/resource/icon checks, script-profile regression and Retina mapping tests passed. The folder browser still needs verification on an actual iPhone or iPad. iOS may restore another Files location; use the manual path below if needed.
