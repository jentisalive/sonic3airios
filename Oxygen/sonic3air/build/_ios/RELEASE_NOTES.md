Экспериментальная нативная сборка Sonic 3 A.I.R. для iPhone и iPad, без WebView.

- Исправлена причина `Failed to load base scripts`: в профиле игры теперь задан `main.lemon`.
- Добавлена стандартная иконка Sonic 3 A.I.R. для iPhone и iPad.
- В журнал добавлен путь загружаемого скрипта для диагностики.

Скачайте **Sonic3AIR-iOS-unsigned.ipa** ниже. Это неподписанная IPA: используйте свой способ подписи и установки. Для запуска нужен совместимый ROM Sonic 3 & Knuckles; он не включён и не скачивается приложением.

При обновлении сохраните папку Documents, чтобы не потерять сохранения и моды. Повторная проверка запуска на устройстве после этого исправления ещё требуется.

Исходники именно этой сборки доступны по тегу `ios-v0.1.1`. Лицензия проекта — GPL-3.0.
